Every pull request now gets a knowledge proposal: `marginal propose --comment`
posts the relations the PR's diff shows (CODEOWNERS owners, dependencies,
version bumps) as one comment, kept up to date on each push; a PR with none
gets no comment.
Merging accepts the claims, and `/marginal drop <id>` from someone with write
access excludes one. No model call.
