New `marginal doctor` command checks your setup before the first review: that
`.marginal/config.yaml` is valid, that `models.reviewer` is set and each
configured provider's API key is in the environment, that `permissions` let
`marginal review --comment` read the PR and post, and that `GITHUB_TOKEN` is
set. With `--repo owner/name` it also makes one read-only GitHub call to
confirm the token is accepted and the repository is reachable. It never calls
a model or posts anything. Each check prints one ✓/✗ line with a fix under
each failure, and the command exits 0 only when every check passes, else 1
