A push that leaves the review prompt unchanged (an empty rebase, a re-run, a push that only touches ignored files) no longer calls the model. Each posted review keeps a hidden hash of the whole prompt -- diff, caller context, policies, accepted knowledge, maintainer replies and CI conclusion -- and `marginal review --comment` skips the model call when the next prompt hashes the same, logging `same prompt as the last review, no model call`. The hash covers `.marginal/config.yaml` too, so switching the reviewer model or changing a setting reviews the PR again.
